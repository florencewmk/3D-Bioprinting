# Papers and full-text sources

The archived full texts are preserved unchanged. This archive contains **21 PDFs and 1 full-text JATS XML article**: 5 PDFs match numbered main references, 16 PDFs are supporting literature, and the XML supports the history sources. Titles and DOIs were checked against metadata and opening pages; the cited book was checked on its title/copyright pages. The Van Ombergen PDF was retrieved from the author-lab Zenodo repository on 3 November 2026; earlier local archives remain unchanged.

- `cited/`: exact matches to numbered scientific references on slides 24–25.
- `supporting/`: relevant existing literature; exact slide/figure use has not been audited.

Third-party copyright and license notices remain in each PDF. These documents are not relicensed under the repository MIT license. The archive includes a cited book and two book chapters, distinguished in the catalog.

## Maintain

When adding a paper, keep the PDF and any supplements in this directory, update the catalog and inventory, and verify the files:

```sh
python3 tools/check_papers.py
```

The IEEE bibliography below uses the same reference numbers as the HTML deck. Recheck slide locations if the slide order changes. After editing IEEE citations
in the catalog, run `python3 tools/reference_slides.py` from the repository root
to refresh the HTML reference pages and transcript.
